## Pages
GitHub Pages 배포 파일과 워크플로는 준비되어 있습니다. 현재 GitHub App 연결에는 저장소의 Pages 사이트를 최초 활성화하는 관리자 권한이 없어 첫 배포만 막힌 상태입니다.

저장소에서 **Settings → Pages → Build and deployment → Source: GitHub Actions**를 한 번 선택하면 이후 `main` 변경 때 자동 배포됩니다.

`gh-pages` 브랜치도 같은 현재 버전으로 만들어 두었습니다. 필요하면 **Deploy from a branch → gh-pages / (root)** 방식도 사용할 수 있습니다.

메인 페이지는 외부 라이브러리 없이 단일 HTML로 동작합니다.
