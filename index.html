1. 표상과 이미지

표상

  • 화면에 들어오는 사람·사물

2. OVT

맡김 · 확인 · 전이

O · Orchestration

  • AI에게 맡길 일
  • 학생이 직접 할 판단
  • 작업 순서
  • 중간에 바꾼 조건
  • 버린 결과와 다시 시킨 이유

V · Verification

  • 원자료와 대조
  • 직접 실행
  • 오답·빈 입력·경계값 시험
  • 다른 기기에서 재확인
  • 수정 뒤 다시 확인

T · Transfer

  • 다른 문제에 그대로 쓸 절차
  • 바꿔야 할 조건
  • 재사용 가능한 질문
  • 검증 순서
  • 다음 과제에서 실제 적용

웹앱 만들기

  
설명 대신 조작 · 실패 · 비교

  

    
개념5~8문장
변수직접 바꾸기
결과즉시 보기
실패경계값·오류
설명왜 그런지 말하기

  

  

    
수학
분수 비교
  • 두 분수 비교
  • 그림 모델 / 공통분모 힌트
  • 정답 뒤 이유 설명
  • 같은 값·1보다 큰 분수 시험
초등학생용 분수 비교 웹앱을 HTML 하나로 만들어줘. 두 분수를 비교하게 하고, 정답 여부에 따라 힌트를 보여줘. 힌트는 그림 모델 또는 공통분모 방식 둘 중 하나로 설명해줘. 같은 값인 경우와 1보다 큰 분수도 테스트할 수 있게 해줘.

    
국어
맞춤법 게임
  • 보기 3개
  • 오답 이유
  • 하트·점수·다시하기
  • 연속 오답 테스트
초등학생용 맞춤법 퀴즈 게임을 HTML 하나로 만들어줘. 보기 3개 중 맞는 표현을 고르게 하고, 오답을 고르면 이유를 짧게 알려줘. 하트 3개, 점수, 다시하기 버튼을 넣어줘. 연속 오답과 마지막 문제에서도 점수가 정확한지 확인할 수 있게 해줘.

    
과학
전기회로
  • 전지·전구·스위치 조합
  • 먼저 예측
  • 켜짐/꺼짐 확인
  • 이유 설명
초등학생용 전기회로 학습 페이지를 HTML 하나로 만들어줘. 여러 회로 그림을 제시하고 전구가 켜질지 먼저 예측하게 해줘. 선택 뒤 결과와 이유를 보여줘. 전선이 끊긴 경우, 스위치가 열린 경우도 포함해줘.

    
영어
역할극
  • 상황 카드
  • 4턴 대화
  • 마지막 문장 직접 말하기
  • 한 표현 바꿔 재사용
초등학생용 영어 역할극 연습 페이지를 HTML 하나로 만들어줘. 상황 카드를 고르면 4턴 대화가 나오고, 마지막 문장은 학생이 직접 말하거나 입력하게 해줘. 같은 표현을 다른 장소·상황으로 바꾸는 버튼도 넣어줘.

    
AI 개념
k-NN 분류
  • 점 직접 찍기
  • k=1·3·5·7 변경
  • 가까운 이웃 표시
  • 경계에서 결과 변화 관찰
